Praticando em HTML

# Sabor e Brasa

Projeto de um restaurante fictício desenvolvido para praticar os fundamentos de HTML5.

## Tecnologias

* HTML5
* Notepad++

## O que foi utilizado

* Títulos
* Parágrafos
* Imagens
* Links
* Listas
* Tabelas
* Favicon

## Sobre o projeto

O projeto apresenta um restaurante fictício chamado **Sabor e Brasa**, com informações sobre o restaurante, pratos e preços.

Este é um projeto desenvolvido durante meus estudos de HTML e representa uma das primeiras etapas da minha aprendizagem em desenvolvimento web.
